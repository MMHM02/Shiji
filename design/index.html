📐 设计规范摘要

  • 品牌色：健康绿 #4CAF50，搭配中性灰 Material 3 调色板
  • 字体：Noto Sans SC（中文）/ Roboto（英文），Roboto Mono（数字）
  • 圆角：16dp 标准卡片 · 12dp 输入框 · 8dp 按钮 · 全圆角胶囊
  • 间距：4dp 栅格系统（8 / 16 / 24 / 32 / 48dp）
  • 图标：Material Icons 线性风格，导航 24dp · 列表 20dp · 按钮 18dp
  • 动效：微交互为主（点击缩放 96% · 800ms 缓出圆环 · 列表过渡）
  • 组件覆盖：Button / Card / Input / Chip / BottomSheet / Dialog / Snackbar / Loading / Empty / Progress / Ring Chart / Line Chart 等 12+ 组件含状态
